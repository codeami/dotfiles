# Dialogue freezes into skills

Claim: A skill and an ICM are both frozen conversations — real dialogue crystallized into a file that can be replayed.

Evidence: "A skill is technically a frozen conversation, a frozen workflow. An ICM is a frozen conversation."

Elaboration:
- The value is your opinion and the way you do the work, not a generic prompt.
- This is the same mechanism backpass exploits: transcripts are the raw signal that becomes instructions.
- "We said, this is how I work, this is when I do it, this is what I do."
