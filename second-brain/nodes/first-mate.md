# First mate

Claim: The endgame is a first mate — one agent you talk to that dispatches, supervises, and validates a crew across worktrees, so you focus on direction.

Evidence: "I needed a first mate, someone I can talk to as a captain that will carry out all my directions and manage all the crewmates."

Elaboration:
- Clone firstmate, run an agent inside it, talk to one liaison; it spawns tabs, calls treehouse, runs no-mistakes, hands back PRs.
- A three-repo task is recognized as three parallel tasks and fanned out automatically.
- "First mate is basically all my tools coming together as one cohesive workflow."
