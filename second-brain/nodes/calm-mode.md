# Calm mode

Claim: Hide tool-call noise; with capable models you only need your prompt and the agent's response, not the step-by-step.

Evidence: "all those noise disappears. The only thing that's going to show in the terminal is my prompt and first mate's response... with today's models, it's actually more and more rare that I need to steer the agent that way."

Elaboration:
- Tool-call watching was for steering weak models; today's models need steering rarely.
- /calm is a presentation-mode toggle, not a capability change — it only hides collapsed noise.
- This is the same ergonomic instinct as AXI: surface signal, not mechanics.
