# ICM: the value ladder — which layer am I standing on?

Claim: Value migrates upward whenever a layer gets commoditised: the raw output (the "book") is what anyone can produce; the flow built from your specific context (the "movie") is where knowledge shows; learning from reviewed results (the "game") is where the system responds. Before building, ask which layer you are on and whether the thing you are building will be a feature of someone else's tool soon.

Evidence: The unnamed Fortune 500 "$200K document workflow" that the platform later shipped; the web agency that moved routine updates into a client portal and kept research, strategy and decisions. "The question was never 'will AI replace me.' The question is: which layer am I standing on, and what does the layer above look like?" Figures are presenter-reported, not verified.

Elaboration:
- Layer 3 is not self-improving: a person reviews evidence, changes one instruction, tests again.
- Keep workflows easy to revise because the tools underneath will change.
- "The whole transaction chain still ends at a person with a preference."

Why it matters here: the Kun Chen stack is Layer 2 infrastructure; the context repo plus backpass review is the Layer 3 loop. For work tooling and the content engine the test is the same: what here is specific to one setup / to Ashish's voice, and what will a vendor ship next quarter?
