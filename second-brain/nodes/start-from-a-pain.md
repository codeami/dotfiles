# Start from a pain, not a plan

Claim: A context layer earns its structure from a recurring pain, not from an upfront taxonomy; building the taxonomy first produces a notes graveyard.

Evidence: "My pain is not that I don't have a second brain. My pain is that I had a process of building these afternoon teas that was slightly annoying and I captured that process." Also: "what is something tedious that you're doing that would benefit from organization?"

Elaboration:
- The wrong start is "we want a second brain for everyone"; the right start is one annoying process worth capturing.
- Security and simplicity favor local, bespoke brains over a premature shared platform.
- The pain decides what fills the layer ladder; the ladder is only the delivery mechanism.
