# Keep only the signal

Claim: Store the distilled conclusion, not the raw source; the model reads what a transcript produced, not every transcript.

Evidence: "The model doesn't need to read every transcript. It needs to be able to find the signal of that transcript."

Elaboration:
- Once you build the deck or the package, future runs read the package, not the transcript.
- "I don't need every note saved... but I do need a good chunk of it. I need the signal, the process."
- The human pulls what mattered; the brain stores that, not the 12 source documents.
