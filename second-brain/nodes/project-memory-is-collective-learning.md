# Project memory is collective learning

Claim: A project memory file is the accumulated corrections of all past sessions — every time the agent errs, correct it and ask it to store the learning.

Evidence: "every time I saw the agent doing something wrong, I would correct it and ask it to remember to not make the same mistake again by storing the learning into this memory file."

Elaboration:
- Built over time, not written by hand up front; it is what the sessions collectively learned.
- This is the manual loop backpass automates: transcript -> correction -> stored instruction.
- "You don't need any fancy memory system to do that. This markdown file is all it takes."
