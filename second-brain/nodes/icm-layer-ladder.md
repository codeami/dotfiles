# ICM layer ladder

Claim: Agent context is best delivered in five numbered layers, each read only when needed — prevention, not compression.

Evidence: "Agents read down five layers and stop when they have what they need." (ICM README)

Elaboration:
- Layer 0 CLAUDE.md / AGENTS.md: where am I (~800 tokens, always loaded).
- Layer 1 CONTEXT.md: where do I go.
- Layer 2 stage CONTEXT.md: what do I do.
- Layer 3 references: what rules apply (the factory).
- Layer 4 artifacts: what am I working with (the product).

Why it matters here: the second brain is this ladder made concrete — AGENTS.md → CONTEXT.md → stage contracts → principles/skills → notes.
