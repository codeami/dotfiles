# Principles (Layer 3 — the factory)

Adapted from ICM's five design principles, restated for a brain:

1. One note, one idea. A note that holds two ideas is two notes in a trenchcoat. Split it.
2. Plain text as the interface. Markdown only; any editor, any agent.
3. Layered context loading. Load the layer you need; never load everything. Prevention, not compression.
4. Every output is an edit surface. Humans and agents both edit; nothing is write-only.
5. Structure decides what matters. The numbering + index + links encode what is important.
6. Dialogue is the source. Skills and workflows crystallize out of real sessions, not out of planning.

Start from a pain, not a plan (see setup/questionnaire.md).
