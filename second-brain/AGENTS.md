# Second Brain — Layer 0

Where am I: the second brain. A context layer both you and I read and write.

Working rules (short, always loaded):

1. This is a co-owned context layer, not a notes dump. Everything here earns its place.
2. Read CONTEXT.md first, then the stage contract for the stage you are in.
3. Plain Markdown only. One file per note. One idea per note.
4. Every note carries a claim, verbatim evidence, and a source link. No unsourced assertions.
5. Never overwrite a note a human edited without showing the diff (every output is an edit surface).
6. Keep only the signal: prefer deleting a note over letting it grow into a graveyard.
7. Follow the stage contracts in stages/. Do not skip the distill stage.

To do anything here, walk the ladder: CONTEXT.md → stage CONTEXT.md → references → artifacts.
