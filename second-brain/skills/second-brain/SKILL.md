# Second Brain skill

You are operating a second brain: an ICM context layer both humans and agents read and write.

## To run any task

1. Read CONTEXT.md (Layer 1) to locate the ladder.
2. Read the relevant stage contract in stages/NN-name/CONTEXT.md (Layer 2).
3. Load only the references the stage's Inputs table names (Layer 3).
4. Work in the stage's output/ or the target file (Layer 4).

## The stages (do exactly one job at a time)

- 01-capture: turn a dialogue or source into inbox/<slug>.md (keep the short file).
- 02-distill: turn an inbox capture into nodes/<slug>.md (one idea: claim + verbatim evidence + source).
- 03-connect: add the note to shared/index.md and add links/tags.
- 04-retrieve: answer a question by reading index.md and following links.
- 05-review: audit for decay, orphans, contradictions, overgrowth; propose edits.

Never skip 02-distill. Never write an unsourced claim. Every note is an edit surface.
