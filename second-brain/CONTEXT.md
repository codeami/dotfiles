# Second Brain — CONTEXT

Where do I go: the routing map.

## The layer ladder

- Layer 0 (AGENTS.md): where am I — always loaded.
- Layer 1 (this file): where do I go — read on entry.
- Layer 2 (stages/NN-name/CONTEXT.md): what do I do — read per task.
- Layer 3 (_config/, skills/, shared/): what rules apply — loaded selectively.
- Layer 4 (inbox/, nodes/, output/): what am I working with — loaded selectively.

## The lifecycle (stages/)

01-capture : dialogue / source → raw capture in inbox/
02-distill : raw capture → atomic note in nodes/ (claim + evidence + source)
03-connect : note → the graph (index + backlinks + tags)
04-retrieve: question → the right note(s), fast
05-review  : audit for decay, orphans, contradictions, overgrowth

## Routing

- New raw material → 01-capture.
- Material sitting in inbox/ → 02-distill.
- A note with no entry in index → 03-connect.
- A question needing context → 04-retrieve.
- Periodic maintenance → 05-review.

## Rules of the house (full detail in _config/)

One idea per note. Keep only the signal. Structure decides what matters.
