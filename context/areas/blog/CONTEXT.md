# Room: blog

Posts that teach one idea simply, for engineers new to agentic AI.

## Process
1. Start from the notes in `../../../codeami/dotfiles/second-brain/nodes/` the task names.
2. One idea per section. Open with an everyday analogy, then the real thing.
3. One plain-text diagram per section at most (folder tree or arrows).
4. Every claim that can be checked gets a "Test:" line pointing at `~/context/tests/`.
5. Save as `drafts/<slug>_draft.md`. Never publish.

## Good looks like
Short paragraphs, concrete examples, honest caveats, sources linked at the end.
Use `template.md` for structure and `voice.md` for tone.
