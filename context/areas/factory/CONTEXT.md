# Room: software factory

Work on any repo through FirstMate and Kun Chen's tools.

## Process
1. Spec and decisions first (plan mode; issues via `gh-axi`).
2. Parallel work in worktrees (`firstmate` + `treehouse`); never on `main`.
3. Overnight loops with `gnhf`, always with a token cap and a stop condition.
4. Push only through `no-mistakes` (review → test → docs → lint → PR).
5. Each project keeps its own `AGENTS.md` (build/test/repo rules) and
   `CLAUDE.md` containing only `@AGENTS.md`.
